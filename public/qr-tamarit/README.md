# QR Tamarit Automoción

Archivos vectoriales listos para imprimir:

- `qr-mesa.svg`: formato A5 horizontal, pensado para soporte de sobremesa.
- `qr-pared.svg`: formato A3 vertical, pensado para pared o escaparate.
- `google-maps-qr.svg`: QR vectorial con destino a la ficha de E.J. Tamarit Automoción en Google Maps.

Los SVG usan Roboto como primera opcion y Arial como respaldo. Al exportar a PDF desde Illustrator, Inkscape o el navegador, mantener la escala al 100% y no rasterizar el QR.
